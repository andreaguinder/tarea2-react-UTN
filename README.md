## ℹ️ Información sobre el proyecto

### Descripción

Se realizaron dos contenedores, uno de un formulario con campos de Nombre y Edad y un botón para enviar y otro con un titulo y una imagen.

El formulario cuenta con validaciones. Si ambos input están vacíos, entonces el botón está deshabilitado, si un campo está lleno, se habilita el botón pero no permite que se envié sino que muestra brevemente un mensaje que le indica al usuario que debe llenarlo totalmente para poder enviarlo.

En el contenedor inferior hay un nombre fantasía del evento al que se desea entrar y una imagen, y debajo de ella aparece el mensaje de bienvenida o el que le niega al usuario la entrada, que aparece dinámicamente con el nombre que ingresó el usuario y luego de la validación de su edad.

## 🚀 Instrucciones de Instalación y Ejecución

Para clonar este proyecto y visualizarlo de forma local en tu navegador, seguí estos pasos:

### 1. Obtener la URL del repositorio
1. Entrá al repositorio en GitHub.
2. Hacé clic en el botón verde que dice **Code** (ubicado arriba a la derecha).
3. Asegurate de seleccionar la pestaña **HTTPS** y copiá la URL que te aparece.

### 2. Clonar el repositorio
Abrí tu terminal o consola de comandos, posicionate en la carpeta donde quieras guardar el proyecto y ejecutá el siguiente comando (reemplazando por la URL que copiaste):

### 3. En la Terminal del Editor de código
git clone [https://github.com/andreaguinder/tarea2-react-UTN.git](https://github.com/andreaguinder/tarea2-react-UTN.git)
